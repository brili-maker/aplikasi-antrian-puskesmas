# Aplikasi Antrian Puskesmas
Java Swing + JDBC + MySQL.

## Cara menjalankan
1. Jalankan MySQL (XAMPP), lalu import schema.sql lewat phpMyAdmin.
2. Ubah db.properties.example menjadi db.properties, isi sesuai MySQL.
3. Buka folder di VS Code, lalu jalankan Main.java.

## Fitur
Pendaftaran pasien, panggil antrian, edit pasien, laporan harian, layar TV.
